# 1.14.0

### What's New

* **Feature Audit Tool** — A new webview-based UI for analyzing BoxLang feature usage across your workspace. Quickly discover which BIFs, components, and language features your project depends on.
* Bumped the internal BoxLang runtime version to **1.9**
* Updated JSON validation schemas for `boxlang.json` and `.bxformat.json`
