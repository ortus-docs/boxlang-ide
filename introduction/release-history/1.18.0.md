# 1.18.0

### What's New

* **LSP Workspace Setting Configuration** — Refined how the language server settings are applied per workspace for more predictable behavior
* **Main Component Auto-Update** — Automatic update checks and downloads for LSP, Debugger, and MiniServer with configurable policies
* **Dump Context Menu** — Right-click any variable in the editor to inspect its value via the debug protocol
