# Configuration

| ID                                        | Description                                                                                                                 |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| boxlang.boxLangHome                       | An alternative location to use as your BoxLang Home                                                                         |
| boxlang.jarpath                           | The path to the boxlang jar you want to use for execution                                                                   |
| boxlang.lsp.enableExperimentalDiagnostics | Enable experimental support for language diagnostics such as unused variables, invalid return statements, dead code, etc... |
